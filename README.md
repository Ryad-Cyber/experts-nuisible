# Experts Nuisible

Site web professionnel réalisé pour une activité spécialisée dans la lutte contre les nuisibles.

## Présentation

Ce projet consiste en la création d'un site web destiné à présenter les services d'une entreprise spécialisée dans le traitement des nuisibles.

Les prestations concernent notamment la lutte contre les :

* Rats
* Souris
* Cafards
* Insectes
* Autres nuisibles

Le site a pour objectif de présenter clairement les services proposés et de permettre aux visiteurs de prendre contact facilement.

## Technologies

* Next.js
* React
* TypeScript / TSX
* Tailwind CSS
* Vercel

## Fonctionnalités

* Présentation des prestations
* Présentation des différents types de nuisibles
* Design responsive
* Interface adaptée aux mobiles et ordinateurs
* Navigation entre les différentes sections du site
* Mise en avant des informations de contact
* Design personnalisé pour l'activité

## Objectif

Créer une présence web professionnelle permettant à l'activité de présenter ses prestations et de faciliter la prise de contact avec les clients.

## Déploiement

Le projet est conçu pour être déployé sur Vercel.
